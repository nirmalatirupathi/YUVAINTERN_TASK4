# YuvaIntern Task 4 – Comprehensive Data Science Report and Insights Presentation Plan

## Project
Customer Churn Prediction and Retention Analytics.

This repository contains the complete Task 4 report and presentation-planning project. It demonstrates how a hypothetical data science analysis can be converted into a clear, persuasive business narrative.

## Important Note
No real customer dataset was supplied for this internship task. Therefore, numerical charts and findings are illustrative mock-ups and must not be presented as actual business results.

## Storytelling Framework
Business challenge → Analytical approach → Key insight → Business implication → Recommended action → Measurement and future work

- `reports/` – completed Word report

- `src/` – code template for generating presentation visuals

- `requirements.txt` – Python dependencies
